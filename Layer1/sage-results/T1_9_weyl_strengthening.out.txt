T1.9 STRENGTHENING — general Maxwell EL + the lambda-constraint term
======================================================================

----------------------------------------------------------------------
(A) Maxwell EL for an ARBITRARY potential A (four free functions)
----------------------------------------------------------------------
  residual per nu (div F - (boxA - grad div A)): [0, 0, 0, 0]
  div_mu F^{mu nu} = box A^nu - d^nu(div A)  for ARBITRARY A: True   [VERIFIED]
  => the F^2-term EL is the 2nd-order Maxwell operator for any A,
     not merely the single plane wave of 02_T1_9. In Lorenz gauge
     (div A = 0) this reduces to box A^nu = 0 (the wave equation).

----------------------------------------------------------------------
(B) lambda term  -lambda(1/2 - 6 phi_i phi^i)  (DT-specific)
----------------------------------------------------------------------
  [multiplier reading, SUPERSEDED] dLc/dlambda = -6*phi0^2 + 6*phi1^2 + 6*phi2^2 + 6*phi3^2 - 1/2
  [multiplier reading, SUPERSEDED] EL(lambda) = 0 => phi_i phi^i = 1/12
  [constant reading, Weyl] lambda is not varied: no norm constraint;
    the -lambda/2 piece is a cosmological constant (weyl_lambda_reading).
  dLc/dphi_k = [-12*lam*phi0, 12*lam*phi1, 12*lam*phi2, 12*lam*phi3]
  dLc/dphi_k = 12 lambda phi^k  (source added to the gauge field eq): True   [VERIFIED]
  => on either reading 12 lambda phi^k enters the gauge field equation:
     A * div_mu F^{mu nu} + 12 lambda phi^nu = 0 -- on the constant (Weyl)
     reading a Proca-type mass, Planck-scale (weyl_vector_mass).

T1.9 STRENGTHENING SUMMARY:
  (A) Maxwell EL generalised from one plane wave to ARBITRARY A:

      EL(phi_k) => 12 lambda phi^k (either reading)            [VERIFIED]
      EL(lambda) => phi^2 = 1/12 only on the SUPERSEDED multiplier reading;
      on Weyl's constant reading: Lambda != 0 and a Proca-type mass.
